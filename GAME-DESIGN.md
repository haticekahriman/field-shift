# Play flow

Choose a historical window and a farm mode. Plant each plot for three seasons, simulate, and inspect the decision report. The report shows when the first water deficit appears and how it changes by month. A feasible single-crop suggestion can be applied in a new run with the same weather. Compare unmet demand alongside shared irrigation, cereal and legume targets, and uncovered plot-days.

Use in a short instructor-led exercise. Ask learners to explain why a plan with a lower modeled deficit can still have a crop-cover trade-off. The optional post-run quiz checks recall. It does not establish learning impact.
